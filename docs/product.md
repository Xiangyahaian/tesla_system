# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

演示与体验场景下的驾驶员 / 副驾乘客。在模拟座舱中控屏上与「小特」对话：问手册、查车况、下控车指令；也可切换座位模拟多乘员。

## Product Purpose

Tesla 智能座舱模拟系统：左侧自然语言对话，右侧实时车况中控。成功标准是演示时「像真车机」——指令有可见反馈、中控有设计感、交互丝滑，而不是后台调试台。

## Positioning

Cabin Runtime V2：语义 NLU + 真流式 + 工具控车 + RAG 手册，前端左右对开驾驶页。差异点在「对话驱动车况变化」的一体体验，而非孤立聊天机器人。

## Operating Context

- 入口：`python run.py`（约 6006）；前端 Vite React HMI
- 主表面：驾驶助手（左右 50/50）、车机应用、执行轨迹、系统设置
- 五座位：主驾 / 副驾 / 左后 / 中后 / 右后；指令默认可跟当前座位
- 语言：全中文 UI

## Brand Commitments

- 助手名「小特」；温暖陪伴语气，但不廉价卖萌
- 用户明确拒绝：AI 紫渐变、淡绿圆角「友好」按钮、卡片堆砌式中控、无质感仪表盘
- 布局约定：驾驶页左右分栏保留；左侧对话、右侧车况

## Constraints

- 保持现有 API / 状态字段与功能路径可用
- 中文可读性优先；不要为装饰牺牲扫读
- 浅色座舱场景（车内日光 / 顶灯），非强制深色整页

## Open Decisions

- 正式品牌资产（Logo 矢量）暂缺，以字标「小特」呈现
